## 3. Les règles qui gouvernent ce projet

Elles sont dans `CLAUDE.md`, `LOOPCRAFT_CONSTITUTION.md`,
`LOOPCRAFT_ROLE_MODEL.md`, `LOOPCRAFT_PRE_CODE_CHECKLIST.md`. **À lire avant
toute modification Loopcraft.** L'essentiel :

- **Conservation absolue** : toute modification est additive, jamais une
  réécriture.
- **Réutiliser les patterns** : une règle métier n'appelle pas une nouvelle UI.
  Déclarer « je réutilise X » ou « je crée Y parce que… ».
- **Versionner avant d'évoluer** : le fichier actif reçoit les modifs, les
  snapshots numérotés sont figés et ne sont jamais retouchés.
- **Tester avec Playwright avant d'affirmer.** Mesurer, ne pas juger à l'œil.
- **Publier sur GitHub après chaque modification**, sans attendre qu'on le
  demande.
- **Ne jamais fermer la fenêtre de test ni couper le serveur** après une
  vérification : Sébastien regarde le résultat.
- Le rôle est **toujours explicite dans l'URL** (`?role=designer` /
  `?role=po&user=X`), jamais déduit de `localhost`.

## 4. Calendrier — état détaillé

**Fichier actif : `wireframe-calendrier-V1.html`.** `V1.0` et `V1.1` sont des
snapshots figés (V1.1 = juste avant le chantier Switch room).

Le parcours **Switch room** est fonctionnel : filtres Category/Occupation
déduits des données, liste qui se resserre (80 → 12 → 5), étiquette de la
chambre retenue à droite du champ, dates saisissables pré-remplies, bouton
désactivé tant qu'aucune chambre n'est choisie, pop-up de confirmation
réutilisant le composant de l'assignation.

**Règles métier tranchées :** une chambre occupée sur la période n'est pas
proposable ; « Swap » est un échange, avec filet de sécurité si un occupant
subsiste.

### Trois pièges rencontrés — ne pas y retomber

1. **`.switch` est déjà l'interrupteur du panel** (44×24px). Nommer une classe
   de tiroir `switch` lui donne cette hauteur → tiroir réduit à 64px.
2. **Un `<input>` en flex ne se comprime pas** sans `min-width: 0`.
3. **Le navigateur sert les wireframes depuis son cache.** Toujours ajouter
   `&cb=<n>` à l'URL pour valider une modif — sinon on teste l'ancienne version
   et on conclut à tort. *Cette erreur a failli faire valider à tort un test
   d'étanchéité.*

`project_loopcraft_shell_partage`.
